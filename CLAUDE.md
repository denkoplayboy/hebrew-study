# Шореш — заметки для доработок

Личное приложение для изучения иврита и английского (интерфейс на русском). Владелец пишет запросы в чат
на русском: «добавь слова…», «сделай упражнение на…», «добавь механику…».

## Стек и структура
- `server/src/` — Hono + better-sqlite3. `index.ts` — все маршруты `/api/*` и раздача `dist/web`.
  `words.ts` — CRUD слов, поиск/дубликаты, грани (facets), применение повторений. `session.ts` — сборка тренировок.
  `ai.ts` — Claude API (structured outputs через `betaZodOutputFormat`, `fallbacks: "default"`). `stats.ts`, `content.ts`, `db.ts` (миграции — массив `MIGRATIONS`, добавлять только в конец).
- `web/src/` — React. `pages/*` — страницы, `exercises/*` — упражнения, `components/*` — общие элементы, `styles.css` — дизайн-токены.
- `shared/` — общий код сервера и клиента: `lang.ts` (нормализация иврита, раскладка, биньяны, гзарот, лица/времена), `memory.ts` (FSRS, грани, стадии), `types.ts`.

## Как добавить слова по просьбе владельца
Создай `content/inbox/<дата>-<тема>.json` вида `{ "words": [ ... ] }` (поля как в `content/seed/01-first-words.json`:
`he`, `he_nikud`, `translit` (кириллица, ה → h, ударение ́), `ru`, `ru_alt`, `en`, `en_alt`, `pos`, `gender`, `plural`, `plural_nikud`,
`root` (`ת-פ-ס`), `binyan`, `gizra`, `notes`, `tags`, `study` (`["he"]`/`["en"]`), `input_lang`, `examples` (с `target` — точная подстрока),
`he_forms` (полное спряжение: tense past/present/future/imperative/infinitive, person как в `shared/lang.ts` PERSONS; для прилагательных/сущ. — tense `infl`),
`en_forms` (past/pp/ing/3s)). Каждый файл импортируется один раз (`settings` хранит `meta:inbox:<файл>`); дубликаты сливаются в существующую карточку.
Удобно генерировать скриптом, как это сделано для `content/packs/starter-verbs.json`.

## Как добавить набор упражнений
`content/packs/<id>.json`: `{ id, title, description, lang, level, items: [...] , words?: [...] }`.
Типы `items`: `info` (title, body), `choice` (prompt, options, answer — индекс; варианты перемешиваются в клиенте),
`fill` (prompt с `___`, answers), `translate` (prompt по-русски, answers), `order` (tokens, answers: [предложение]). Везде `explain`.

## ИИ и расходы
- Модель и «усилие» задаются по операциям (`analyze`, `conjugate`, `check`) в настройках приложения (`settings.aiProfile`), по умолчанию — `AI_MODEL` (Opus 5.5).
- Каждый запрос пишется в `ai_usage` (токены и стоимость по ценам из `PRICES` в `ai.ts`); ответы разбора и спряжения кэшируются в `ai_cache` на 30 дней.
- При правке промптов в `ai.ts` увеличь `PROMPT_VERSION`, иначе из кэша будут отдаваться ответы старой версии.
- Haiku не поддерживает серверный fallback — для него параметр `fallbacks` не отправляется.

## Роса и игровое поле «Шук» (Лавка)
- Роса (`server/src/economy.ts`) капает только за работу памяти: повторение навыка, который был новым или «хотел пить» (`FACET_DEW`), рост стадии, самостоятельное употребление, полностью политый сад (раз в день); с потолком — блиц и наборы. Никаких наград за вход и серий.
- Тратится на поле «Шук» (`shared/board.ts` — клетки, районы, здания и их уровни; `server/src/game.ts` — броски, клетки, покупки, постройки, `perks()`). Бросок платный (10 росы, дорожает после 3 платных бросков за день), участок покупается только стоя на нём, здание (3 уровня) строится в любой момент.
- Здания (`BUILDINGS`, клетка → здание в `CELLS`), что открывает каждое — вычисляет `perks()`:
  Порт Яффо (+10/20/30% росы за все уроки), Дизайн-студия (темы `data-accent`, шрифты иврита, деревья `Plant` в `components/ui.tsx`, листопад),
  Чёрный рынок на Адаре (сильные эффекты уроков: пропуск, тройная роса, щит, сундук финиша, джекпот), Кафе на Кармеле (Ноа, см. ниже),
  Колесо Цфата (обороты в день, приз забирается ответом на вопрос по своим словам), Арена Тверии («Блиц», «Диктант», марафон),
  Хостел (доход после первого урока дня), Кафе «Ход» (двойная роса, золотой час, жетоны подсказки и второй попытки, утренний кофе),
  ИИ-здания: Кафе «Сиппур» (сказки, темы, сериал) и Архив корней. Эффекты — `EFFECTS` (поле `shop`: `cafe`/`black`), таблица `effects`,
  итог урока — `completeSession()` в `game.ts` (`/api/session/complete`). Прогноз, режим «На грани» и экспорт CSV/TSV — бесплатны.
- Ноа (`server/src/girl.ts`, страница `web/src/pages/Carmel.tsx`): близость `girl:affinity` (прирост ≤120 в день, стадии `GIRL_STAGES`),
  подарки `GIFTS` (любимый подарок недели ×2), отдать росу, разговор на иврите (`girlChat` в `ai.ts`, самостоятельно употреблённые слова
  засчитываются), просьбы: `judgeWish` назначает цену и действия (`actions`), после оплаты они выполняются (таблица `wishes`, журнал `girl_log`).
- Новое здание/перк: запись в `BUILDINGS` и клетка в `CELLS`, флаг в `Perks` и `perks()`, проверка в нужном месте (сессия/маршрут/настройки), кнопка в `web/src/pages/Shop.tsx` (`BuildingLinks`).
- После добавления слова ИИ возвращает ровно два `related`: одно того же корня в другом биньяне/части речи (`kind: "morph"`) и одно
  близкое по смыслу — синоним, антоним или слово, которое часто стоит рядом (`synonym`/`antonym`/`collocation`). Показываются плашкой и на странице слова.

## Принципы
- Ктив мале без огласовок в `he`/`form`, огласовки — в `he_nikud`/`nikud`. Ответы сравниваются без огласовок, разница י/ו = «почти верно».
- Интерфейс и все пояснения — по-русски. Дизайн: мягкие углы, нейтральные цвета, без эмодзи и геймификации в стиле Duolingo.
- Проверка перед коммитом: `npm run typecheck && npm run build`.

## Дизайн: impeccable
- Скилл `/impeccable` (`.claude/skills/impeccable`, агенты в `.claude/agents`, хуки детектора в `.claude/settings.json`). Контекст продукта — `PRODUCT.md`.
- Движок: бинарник в `scripts/bin/` не коммитится, лаунчер берёт глобальный `impeccable` (ставится скриптом облачной среды: `npm i -g impeccable@4.9.1`).
- Полная проверка — по запущенному приложению: `AI_MOCK=1 DATA_DIR=/tmp/shoresh PORT=8099 node dist/server/src/index.js`, затем Chromium с `--headless=new --no-sandbox --remote-debugging-port=9222` и `.claude/skills/impeccable/scripts/impeccable detect --cdp 9222 --target localhost`.

## Мобильное приложение (Capacitor)
- Та же сборка `web/` в нативной оболочке: `capacitor.config.ts`, проекты `android/` и `ios/`, исходники иконки и заставки — `resources/` (`npx @capacitor/assets generate`).
- Ключ Claude в приложение НЕ кладётся никогда: ИИ и данные идут через сервер. Приложение логинится паролем, сервер отдаёт токен (`/api/login` → `token`), дальше `Authorization: Bearer`. CORS на сервере открыт только для `capacitor://localhost`, `https://localhost`, `http://localhost`.
- Адрес сервера по умолчанию задаётся при сборке: `VITE_API_BASE=https://<приложение>.fly.dev npm run build:app`; в приложении его можно поменять на экране входа.
- Всё нативное — в `web/src/lib/native.ts` (вибрация, системная озвучка, статусная строка, кнопка «назад», напоминание). На сайте эти функции ничего не делают.
- Сборка APK: `cd android && ./gradlew assembleDebug` (нужен Android SDK, `ANDROID_HOME`). iOS собирается только на Mac в Xcode: `npm run app:ios`.
