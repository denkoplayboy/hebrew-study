# Шореш · שורש

Личный «сад слов» для изучения **иврита** и **английского** (родной язык интерфейса — русский).
Каждое слово — растение. Оно растёт, когда ты его узнаёшь, вспоминаешь, пишешь, подставляешь в контекст и
сам употребляешь в речи. И увядает, если его не «поливать».

Открывается с телефона и компьютера (можно установить на экран «Домой» как приложение).

---

## Что внутри

**Единый поиск/добавление.** Одно поле ищет по ивриту, русскому и английскому, по любой форме слова
(`נתפסתי` → `להיתפס`, `ראיות` → `ראיה`, `והמחשב` → `מחשב`). Если слова нет — кнопка «Добавить»:
ИИ приводит его к словарной форме, переводит на два других языка, определяет корень, биньян, гизру,
род, мн. число, даёт транскрипцию, заметки об управлении и примеры. Можно вставить сразу список через запятую.
Если понятие уже есть (например, «buy» при наличии `לקנות`), карточка дополняется, а не дублируется.

**Многомерная память.** У каждого слова 6–7 навыков, у каждого своё расписание повторений (алгоритм FSRS):

| Навык | Как тренируется |
|---|---|
| Узнавание | карточки, быстрый выбор, пары |
| На слух | слово звучит — выбираешь смысл |
| Вспоминание | по-русски → пишешь слово сам |
| Написание | точность написания в том же упражнении |
| В контексте | предложение с пропуском, нужна правильная форма |
| Употребление | своя фраза со словом; дневник |
| Формы | спряжение глаголов / формы английских неправильных глаголов |

Навыки открываются лестницей: узнал → вспомнил → контекст/формы → употребил. Если ты **сам, без подсказки**,
использовал слово в дневнике или в чужом упражнении — это засчитывается как самое сильное доказательство знания.

**Стадии роста** (вместо очков и «огоньков»): Семя → Росток → Саженец → Деревце → Дерево → Укоренилось.
На главной — не XP, а честные метрики: *пассивный запас*, *активный запас*, *живая речь* и прогноз,
сколько из этого увянет за неделю без практики. «Ритм» вместо стрика — без наказания за пропущенный день.

**Режимы практики:** Полив (умная смесь всего, что пора), Карточки, Быстрый выбор, Вспомни сам,
На слух, В контексте, Своя фраза (проверка ИИ), Спряжение, Разбор формы (биньян/время/лицо/корень),
Пары, Близнецы (слова, которые ты путал), Слабые места.

**Механики-эксперименты:**
- *Ставка уверенности* — перед проверкой выбираешь «наугад / думаю / уверен». Это влияет на интервал,
  а в статистике видно, насколько хорошо ты чувствуешь собственное знание (калибровка).
- *Близнецы* — приложение запоминает, какие слова ты путаешь, и сталкивает их лбами.
- *Беглость* — время ответа: «знаю, но медленно» отличается от «знаю автоматически».
- *Сад корней* — слова сгруппированы по שורש, видно, как разрастается семья.
- *Читалка* — вставляешь текст, слова подсвечиваются по стадии роста, незнакомые добавляются в один клик.
- *Дневник* — свободное письмо с исправлениями ИИ и «приглашёнными» словами (видишь только смысл по-русски).
- *Лаборатория* — наборы упражнений по грамматике; новые наборы ИИ создаёт по запросу («סמיכות», «Present Perfect»).
- Ввод иврита с любой раскладки (латиница/кириллица → израильская раскладка) и экранная клавиатура.
- Озвучка через голос устройства, тёмная тема, резервная копия в один файл.

Стартовый контент: твои первые слова (`ראיה`, `חיוני`, `חשוף`, `להיתפס` — с полным спряжением),
набор «Опорные глаголы» (12 моделей по всем биньянам и гзарот), 15 неправильных английских глаголов,
наборы упражнений по предлогам с суффиксами, биньянам и Present Perfect.

## Деплой на fly.io

Нужны: аккаунт на [fly.io](https://fly.io) и (по желанию, но очень рекомендую) ключ Claude API
с [console.anthropic.com](https://console.anthropic.com).

### Вариант А — через flyctl (самый надёжный)

```bash
# 1. Установить flyctl и войти
curl -L https://fly.io/install.sh | sh
fly auth login

# 2. В папке проекта: создать приложение (имя в fly.toml можно поменять — оно станет адресом)
fly apps create shoresh

# 3. Создать постоянный диск для базы (1 ГБ хватит на годы)
fly volumes create shoresh_data --region fra --size 1

# 4. Секреты: пароль для входа и ключ ИИ
fly secrets set APP_PASSWORD='придумай-пароль' ANTHROPIC_API_KEY='sk-ant-...'

# 5. Деплой
fly deploy
```

Приложение будет на `https://<имя>.fly.dev`.

### Вариант Б — автодеплой из GitHub

1. Один раз выполни шаги 1–4 из варианта А (приложение, диск, секреты).
2. Создай токен: `fly tokens create deploy -x 999999h`.
3. В GitHub: *Settings → Secrets and variables → Actions → New repository secret*, имя `FLY_API_TOKEN`.
4. Теперь каждый пуш в `main` сам выкатывает новую версию (`.github/workflows/fly-deploy.yml`).

> Если подключаешь репозиторий через кнопку «Launch from GitHub» в панели fly.io — тоже работает:
> fly возьмёт `Dockerfile` и `fly.toml`. Главное — не забыть том `shoresh_data` и секреты.

### Переменные окружения

| Переменная | Зачем |
|---|---|
| `APP_PASSWORD` | пароль входа. Без него сайт открыт всем, кто знает адрес — **обязательно задай** |
| `ANTHROPIC_API_KEY` | включает ИИ: разбор слов, спряжения, проверка фраз и дневника, генерация наборов |
| `AI_MODEL` | модель Claude, по умолчанию `claude-opus-5-5`. Для экономии можно `claude-haiku-5-5` |
| `AI_EFFORT` | `low` / `medium` / `high` — глубина «размышлений» модели (по умолчанию подобрана под задачу) |

Без ключа ИИ приложение полностью работает, просто слова заполняются вручную, а проверка фраз — самопроверка.
ИИ-запросы используют серверный резервный переход на другую модель, если основная откажется отвечать.

## Локальный запуск

```bash
npm install
npm run dev        # сервер на :8080 + интерфейс на http://localhost:5173
```

Продакшен-сборка: `npm run build && npm start`. База — `data/shoresh.db` (или `$DATA_DIR`).

## Как добавлять контент

- **Через сайт:** слова (поиск/добавление), наборы упражнений (Лаборатория → «Новый набор с ИИ»).
- **Через меня (Claude):** напиши в чат, что добавить, — я положу файлы в репозиторий:
  - `content/inbox/*.json` — слова, импортируются один раз при запуске (дубликаты дополняются, а не повторяются);
  - `content/packs/*.json` — наборы упражнений (обновляются при каждом деплое).

## Резервная копия

Настройки → «Скачать копию» — один JSON со всеми словами, историей повторений и дневником.
Там же — восстановление.

## Устройство

- `server/` — Node.js + Hono + SQLite (better-sqlite3), Claude API через `@anthropic-ai/sdk`.
- `web/` — React + Vite, без UI-фреймворков: свой дизайн (мягкие углы, нейтральные тёплые цвета).
- `shared/` — общая логика: нормализация иврита, проверка ответов, модель памяти (FSRS), справочники биньянов/гзарот.
- `content/` — стартовые слова и наборы упражнений.
