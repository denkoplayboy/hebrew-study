# Входящие слова

Сюда Claude кладёт JSON-файлы со словами, которые нужно добавить в словарь
(когда ты пишешь в чат «добавь эти слова…»). Каждый файл импортируется **один раз**
при старте приложения; уже существующие слова не дублируются, а дополняются.

Формат: `{ "words": [ { "he": "…", "he_nikud": "…", "ru": "…", "en": "…", ... } ] }` —
те же поля, что в `content/seed/01-first-words.json`.
